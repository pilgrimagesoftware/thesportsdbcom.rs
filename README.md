# thesportsdbcom.rs

[![Crates.io](https://img.shields.io/crates/v/thesportsdbcom.svg)](https://crates.io/crates/thesportsdbcom)
[![docs.rs](https://img.shields.io/docsrs/thesportsdbcom)](https://docs.rs/thesportsdbcom)
[![CI](https://github.com/pilgrimagesoftware/thesportsdbcom.rs/actions/workflows/ci.yaml/badge.svg)](https://github.com/pilgrimagesoftware/thesportsdbcom.rs/actions/workflows/ci.yaml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE.md)

This is a Rust client for accessing the [TheSportsDB API](https://www.thesportsdb.com/api.php).

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
thesportsdbcom = "0.1"
```
